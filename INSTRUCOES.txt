MÓDULO PLANEJAMENTO EXPORTAÇÃO 2027

1. Faça backup do projeto D:\matinal-web.
2. Copie as pastas app e lib sobre D:\matinal-web (apenas os arquivos deste pacote).
3. No Google Apps Script, adicione "PLANEJAMENTO EXPORTAÇÃO 2027.xlsx" a ARQUIVOS_PERMITIDOS e publique uma NOVA VERSÃO da implantação existente.
4. Em D:\matinal-web\lib\drive-source.ts, adicione 'PLANEJAMENTO EXPORTAÇÃO 2027.xlsx', dentro do Set allowed (sem apagar as demais entradas).
5. Certifique-se de que ambas as planilhas estejam na pasta Dados Matinal.
6. Execute npm run build e depois npm run dev.
7. Acesse /export/planejamento.

IMPORTANTE: Mês Cadastro = mês de entrada. Mês Entrega = faturamento previsto, não faturamento efetivo.
2026 na planilha Meta 2027 contém apenas janeiro a setembro.
Estimativa sazonal não é ML treinado.
